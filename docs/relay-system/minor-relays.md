when allocating asking calls; opener's answers count it normally.

Practice ordinary two-suiters have five-plus diamonds and exactly four in the
second suit. Named 5/5 and three-suited cases are added explicitly. The rare
balanced subset is long diamonds with all outside suits two/three cards,
restricted to 12–13. Responder has 14–22, no five-card major and two-plus diamonds.

After a poor answer, the next permitted step continues shape; all other
unassigned bids are to play. That re-relay uses the entry's ordinary category
order, omitting categories impossible in the disclosed weak range. Its bids
must be recounted from the new ask. Do not reuse the non-poor literal bids.

The user confirmed on 21 October 2026 that 1D–1S–2C admits 9–22 HCP, including
11-counts. The common expanded-entry practice filter therefore has no HCP gap:

numeric practice cutoff does not settle which exceptionally poor 11-counts
the partnership would judge as weak. Named support and rare balanced cases
retain their source limits. These entries give responder 12–22 and four–six
cards in the initially shown major.

## Trump agreement and transition to keycards

| Priority after a completed description | Agreement |
|---|---|
| First | Retain current/provisional opening minor |
| Next, if shown | Opener's second suit |
| Next, when nonshortage is known | Responder's suit |
| Next, if shown | Opener's four-card third suit |
| Last alternative | Other minor for responder's surprise long minor |

Only available alternatives receive a call; calls skip responder's reserved
3NT. After changing trump, the new king/queen determine keycards. The first
KC enquiry closes alternative agreements. In the base diamond relay, clubs
cannot be agreed after opener has shown club shortage; the separate 2S
solid-club entry should have been used instead.

Once shape is complete, go directly to SKC when a shortage is known, ordinary
KC otherwise. There is no redundant strength ask or removal of the 0/3 KC rung.
The email does not define new KC/queen/specific-suit response alphabets; use
the [shared slam tables](major-and-slam.md).
