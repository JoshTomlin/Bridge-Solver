# Recorded Results

These files preserve specific experiments with their seeds, search limits, and
engine settings. They are useful for checking claims in the design documents
and for reproducing known failure modes.

They are not rolling benchmarks. The engine has changed between some reports,
and wall-clock timings depend on the machine and build. Prefer exact-oracle
pass rates, same-world comparisons, and invariant checks when evaluating the
current implementation.
