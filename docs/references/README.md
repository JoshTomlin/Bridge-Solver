# Research References

The project includes local copies of the two papers used to implement and audit
alpha-mu:

- [Alpha-Mu Search Algorithm for Bridge](alpha-mu-search-algorithm-for-bridge.pdf)
- [Optimising Alpha-Mu](optimising-alpha-mu.pdf)

[`example-hands.txt`](example-hands.txt) contains small authored bridge positions
used by the early native demonstrations. These files are inputs and references;
the current implementation is documented in [alpha-mu](../alpha-mu.md) and the
[optimization guide](../alpha-mu-optimizations.md).
